## 已安装运行时升级的任务连续性修复

- 修复新插件脚本错误复用旧组件解释器、导致远端工具调用无法分派的问题；启动时使用同一份已激活配置记录的解释器和保留脚本目录。
- 安装先验证组件 API，缺少新 API 时复用共享组件构建器准备独立运行时，通过后才切换配置；候选准备失败时保留旧任务入口和配置。
- 插件脚本按版本和内容摘要存放，使用原子目录发布；覆盖原生安装目录不会覆盖仍在使用的旧脚本。已有任务状态和用户配置字段保留。
- 真实旧版本验收覆盖旧插件初始化、原生目录覆盖、准备失败、组件升级以及升级前后的 MCP 调用；新增 Linux/Windows CI。无用户业务服务器或 NPU 精度实测声明。
