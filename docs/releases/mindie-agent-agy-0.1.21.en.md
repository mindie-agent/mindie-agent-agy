# mindie-agent-agy 0.1.21: Great Subtraction (5-Script Thin Plugin), 12-Tool `agy` Profile, and One-Line Install

[中文](mindie-agent-agy-0.1.21.md)

- **Great Subtraction**: deleted 14 legacy duplicate runtime modules (`admission.py`, `bounded.py`, `component_update.py`, `diagnostic_support.py`, `experiment_ledger.py`, `host_adapter.py`, `identity.py`, `knowledge_cli.py`, `organizer.py`, `paths.py`, `rsi_loop.py`, `setup_sharing.py`, `storage_lifecycle.py`, `update_failures.py`). Production scripts are now **5 thin files** (`mindie_launch.py`, `bridge.py`, `mcp_server.py`, `agy_transcript.py`, `setup.py`) totaling `855` lines (`<= 1,200`).
- **`mindie-harness v0.1.3` seed handshake**: `mindie_launch.verify_seed_bundle` verifies `assets/mindie-harness-seed.pyz` against `seed-lock.json` (`mindie-harness-seed/1`) in `64 KiB` chunks; cold starts provision through the seed and re-enter this plugin. New `plugins/mindie-agent/runtime-requirements.txt` (10 exact component pins) lets a standalone copied `plugins/mindie-agent/` cold-bootstrap. The frozen `hooks.json` remains `979` bytes / `33b564c7...`.
- **12-tool `agy` profile and `mindie_doctor`**: `mcp_config.json` switches `REMOTE_DEV_HARNESS_PROFILE` from `canonical` to `agy`, exposing Antigravity's native 12 tools. `AGYManagedAdapter` enforces `REMOTE_DEV_STATE_DIR` / `REMOTE_DEV_HARNESS_PROFILE=agy` and falls back through `ensure_service` + `rpc` on `knowledge_unavailable` while preserving Receipt Honesty. `mindie-tools` exposes component tools, `mindie_doctor`, and the five `knowledge_*` tools; standard MCP calls need zero `_meta` and zero `PreToolUse` binds (`P2.7`).
- **`< 30ms` hook fast paths**: `pre-invocation` is zero-I/O `{}`; `pre-tool-use` returns `{"decision": "allow"}` with zero binding and rejects forged `_session_id` / `_activation` / `mindie_activation`; `session-start` atomically writes `pending-update-check.json`; `stop` returns `{}` in `< 30ms` with zero SQLite when unconfigured, disabled, or out of scope, and **never returns `{"decision": "continue"}`**. Explicitly revoked leases are never auto-reactivated.
- **UX upgrade**: README / README.en / `docs/install/` now center on `uv run https://github.com/mindie-agent/mindie-agent/releases/latest/download/install.py --host agy`; `gh` is optional and never a blocker; a 3-question dynamic `ask_question` onboarding covers the workspace, a `gh`-aware `contribute` / `local-only` recommendation, and a one-step SSH NPU connection with the terminal-mode `--password` prompt at the end; `mindie_doctor` readiness and a polite one-line Star postscript complete the flow.
- **Tests and CI**: added the isolated `tests/test_agy_plugin.py`, `tests/test_agy_lifecycle.py`, `tests/test_agy_mcp_and_knowledge.py`, and `tests/test_runtime_upgrade.py`, covering frozen `hooks.json` / `mcp_config.json`, seed verification, compatibility AST resolution, cold/disabled/out-of-scope `Stop`, `local-only` / `contribute` capture with explicit revocation, the 12-tool remote catalog, zero-`_meta` knowledge reads with Receipt Honesty, read-only `setup --dry-run`, sharing tiers, and harness generation activation/rebinding. `tests.yml` smoke now calls `mindie_launch.verify_seed_bundle`; `release.yml` points at the `0.1.21` release notes.
