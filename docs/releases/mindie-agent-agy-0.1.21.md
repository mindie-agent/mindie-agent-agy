# mindie-agent-agy 0.1.21：大减法 5 脚本薄插件、12 工具 `agy` Profile 与一句话安装

[English](mindie-agent-agy-0.1.21.en.md)

- **大减法（Great Subtraction）**：删除 14 个遗留重复运行时模块（`admission.py`、`bounded.py`、`component_update.py`、`diagnostic_support.py`、`experiment_ledger.py`、`host_adapter.py`、`identity.py`、`knowledge_cli.py`、`organizer.py`、`paths.py`、`rsi_loop.py`、`setup_sharing.py`、`storage_lifecycle.py`、`update_failures.py`），生产脚本收敛为 **5 个薄文件**（`mindie_launch.py`、`bridge.py`、`mcp_server.py`、`agy_transcript.py`、`setup.py`），总行数 `855` 行（`<= 1,200`）。
- **`mindie-harness v0.1.3` 种子握手**：`mindie_launch.verify_seed_bundle` 以 `64 KiB` 分块校验 `assets/mindie-harness-seed.pyz` 与 `seed-lock.json`（`mindie-harness-seed/1`），冷启动经种子 provision 后回到本插件；新增 `plugins/mindie-agent/runtime-requirements.txt`（10 行精确组件 pin），使独立复制的 `plugins/mindie-agent/` 也可冷自举。冻结 `hooks.json` 保持 `979` 字节 / `33b564c7...` 不变。
- **12 工具 `agy` Profile 与 `mindie_doctor`**：`mcp_config.json` 将 `REMOTE_DEV_HARNESS_PROFILE` 从 `canonical` 改为 `agy`，直接暴露 Antigravity 原生 12 工具；`AGYManagedAdapter` 强制 `REMOTE_DEV_STATE_DIR` / `REMOTE_DEV_HARNESS_PROFILE` 并在 `knowledge_unavailable` 时经 `ensure_service` + `rpc` 回退，保持 Receipt Honesty。`mindie-tools` 暴露组件工具、`mindie_doctor` 与 5 个 `knowledge_*` 工具；所有标准 MCP 调用零 `_meta`、零 `PreToolUse` 绑定（`P2.7`）。
- **`< 30ms` Hook 快路径**：`pre-invocation` 零 I/O `{}`；`pre-tool-use` 零绑定 `{"decision": "allow"}` 并拒绝伪造 `_session_id` / `_activation` / `mindie_activation`；`session-start` 原子写入 `pending-update-check.json`；`stop` 在未配置、禁用或范围外时 `< 30ms` 返回 `{}`、零 SQLite，且**绝不返回 `{"decision": "continue"}`**；显式撤销租约永不被自动重新激活。
- **UX 升级**：README / README.en / `docs/install/` 统一为 `uv run https://github.com/mindie-agent/mindie-agent/releases/latest/download/install.py --host agy` 一句话安装；`gh` 仅作可选增强；3 问动态 `ask_question` onboarding（工作区、按 `gh` 登录状态动态推荐 `contribute` / `local-only`、一步 SSH NPU 连接且终端模式最后输入 `--password`）；`mindie_doctor` 就绪检查与礼貌单行 Star 后记。
- **测试与 CI**：新增隔离的 `tests/test_agy_plugin.py`、`tests/test_agy_lifecycle.py`、`tests/test_agy_mcp_and_knowledge.py`、`tests/test_runtime_upgrade.py`，覆盖冻结 `hooks.json`/`mcp_config.json`、种子校验、兼容性 AST 解析、冷/禁用/范围外 `Stop`、`local-only` / `contribute` 捕获与显式撤销、12 工具 remote catalog、零 `_meta` 知识读取与 Receipt Honesty、`setup --dry-run` 只读保证、共享层级与 harness 代际激活/重绑定；`tests.yml` smoke 改用 `mindie_launch.verify_seed_bundle`，`release.yml` 指向 `0.1.21` 发布说明。
