# mindie-agent-agy 0.1.16: Storage Lifecycle Governance & Component Version Lock

[中文](mindie-agent-agy-0.1.16.md)

- **Cross-process update mutex & two-phase post-switch retirement (`component_update.py`, `setup.py`, new `storage_lifecycle.py`)**: `component_update.check()` performs the build and switch under `<data_home>/agy-component-update.lock`; a concurrent caller waits a bounded interval and then reports an honest `status="busy"` instead of racing the same generation. After the atomic `agy.json` / `agy.engine.json` switch, a separate bounded budget invokes `mindie_knowledge.storage.prune_component_runtimes` and `sweep_legacy_installations` to silently reclaim superseded `component-runtimes` generations, half-finished staging, and older `agy-source` generations while retaining the active generation, its most recent rollback generation, cross-plugin borrowed interpreters, and live leases/processes; every configured external user Git checkout stays a forbidden root. A deferred reclaim or `PermissionError` keeps `status="updated"` and only appends `cleanup_warning`.
- **Resident MCP runtime lease (`mcp_server.py`)**: the resident stdio server holds a shared `acquire_runtime_lease` on the managed generation that owns `sys.executable` for its whole lifetime, so a concurrent two-phase retirement cannot move the interpreter that is serving requests. A missing or read-only generation degrades to no lease and never blocks startup.
- **No redundant baseline `agy-venv` (`setup.py`)**: when the profile's recorded `current_python` still provides the runtime APIs, the component upgrade runs in place through that interpreter; a cold `agy-venv` is built only when no usable interpreter exists, and its uv cache is pinned to the same-volume `<data_home>/.uv-cache` when `UV_CACHE_DIR` is unset.
- **Test isolation fix (`tests/test_runtime_upgrade.py`)**: removes the `mindie-upgrade-*` temporary directory created under `ROOT.parent`, uses the isolated `tmp_path` with deterministic cleanup and parent assertions, and adds `tests/test_storage_lifecycle_agy.py` covering multi-generation reclamation, concurrent mutex protection, real subprocess lease protection, and NTFS `PermissionError` zero-half-delete bounded backoff.
- **Locked component baseline**: `mindie-knowledge` 0.13.22, `remote-dev` 0.11.12, `mindie-diagnostics` 0.5.15, `mindie-coordinator` 0.7.11, `mindie-debugger` 0.1.3, `mindie-profiler` 0.5.15, `mindie-sim` 0.9.15, and `npu-top` 0.3.4 are pinned to their formal commits in `pyproject.toml` (`[tool.uv.sources]` / `override-dependencies`) with a matching `uv.lock`.
