# Default Session & Capture Lifecycle in Antigravity

- **Default-Enabled While Plugin Is Active**: Enabling the `mindie-agent` plugin in Antigravity activates `mindie-remote-dev` (the 12 native `agy` tools) and `mindie-tools` (component tools + `mindie_doctor` + `knowledge_*`) silently by default, while `disable-slash-command: true` hides the skill from the user `/` menu so Antigravity loads `SKILL.md` automatically by task context.
- **Zero Pre-Call Binding (`P2.7`)**: standard MCP `tools/call` never needs `_meta`, a `PreToolUse` bind, or `AGY_CONVERSATION_ID`; identity falls back to the connection scope. `hook pre-tool-use` only rejects forged `_session_id` / `_activation` / `mindie_activation` fields (or a malformed `session_id` on `knowledge_*`) and otherwise returns `{"decision": "allow"}`.
- **`< 30ms` Passive Hooks**: `hook pre-invocation` returns `{}` with zero I/O; `hook session-start` atomically enqueues `state/agy/pending-update-check.json`; unconfigured, sharing-disabled, or out-of-scope `hook stop` returns `{}` with zero SQLite and zero transcript reads.
- **Turn-End `Stop` Capture**: `bridge.py stop` re-verifies `sharing_status(profile, cwd=workspace)` for `contribute` / `local-only` tiers and scope. An explicitly revoked (`status == "inactive"`) lease is never reactivated. For authorized workspaces it provisions a default lease (`not_before=0.0`) and hands off `transcript_full.jsonl` (or `transcript.jsonl`) to `mindie_knowledge.loop.cli.capture_hook` without forcing model continuation (`decision != "continue"`).
- **Sharing Control**: `setup.py sharing --enable | --local-only | --disable` changes consent; `--status` is read-only and creates no files.
