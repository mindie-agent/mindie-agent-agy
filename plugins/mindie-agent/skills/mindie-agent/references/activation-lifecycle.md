# Default Session & Capture Lifecycle in Antigravity

- **Default-Enabled While Plugin Is Active**: Enabling the `mindie-agent` plugin in Antigravity activates `mindie-remote-dev` and `mindie-tools` (including `knowledge_query`, `knowledge_explain`, `knowledge_feedback`, `knowledge_distill`, and `knowledge_sync`) silently by default, while `disable-slash-command: true` hides the skill from the user `/` menu so Antigravity loads `SKILL.md` automatically by task context.
- **Per-Conversation Isolation**: Each Antigravity conversation and subagent owns an independent UUID `conversationId` for `admission.sqlite3` leases, 120s one-shot `PreToolUse` binds, and incremental transcript cursors.
- **Turn-End `Stop` Capture**: `bridge.py stop` checks `agy.json` and community sharing authority (`mindie-community.json` + `project_roots` scope) first, returning `{}` in `< 100ms` with zero SQLite writes when sharing is disabled or out of scope; for authorized workspaces, it provisions a default lease (`not_before=0.0`) and hands off `transcript_full.jsonl` (or `transcript.jsonl`) to `mindie_knowledge.loop.cli.capture_hook` without blocking or forcing model continuation (`decision != "continue"`).
